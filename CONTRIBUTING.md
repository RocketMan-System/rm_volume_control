# Contributing

Contributions are welcome: bug reports, ideas and pull requests.

## Before you start

- Read [AGENT.md](AGENT.md): it describes the architecture, the threading rules and how releases work.
- Run `cargo fmt`, `cargo clippy --all-targets` (must stay warning-free) and `cargo test` before opening a pull request.
- Add unit tests for new logic and translations (en / uk / ru) for new UI strings.
